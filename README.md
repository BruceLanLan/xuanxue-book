## 关于本书

这是一部系统梳理中国古代玄学秘术的综合性研究著作。全书以**纪实叙事**为骨架，以**古籍考证**为血肉，以**民间访谈**为灵魂，深入探索38种濒临失传或已经失传的中国古代秘术体系。

每一章都遵循"古籍考证→正史纪实→民间访谈/田野调查→现代科学假说→传承反思"的五层叙事结构，力求在严谨与可读性之间取得平衡。

## 精彩摘录

> **太素脉法**：嘉祐末年，一个来自随州的僧人被召入北宋都城开封。他被安排住在相国寺——这座始建于北齐天保六年的千年古刹。智缘的到来在京城引发了轰动。他的脉诊能力远超常规医术的范畴——不仅能诊断疾病，更能通过脉象读取一个人的社会地位、未来运势和吉凶休咎。

> **铁板神数**：倪匡坐定后，董慕节拨动算盘，报出一个数字，翻开条文："某年某月某日午时生。"倪匡大惊——这正是他的准确出生时辰。接着第二条："兄弟六人。"第三条："有一兄在大陆，生死不明。"

> **赶尸术**：田铁武回忆他最后一次赶尸经历时说："那是1949年冬天，我从沅陵接了三具尸体，要送回凤凰。路上遇到解放军的部队，我只好把尸体藏在路边的山洞里，等部队过去再继续走。那是我最后一次赶尸了。"
