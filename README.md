## 这本书是什么

这不是一本"周易入门"或"风水常识"的泛泛之谈。

这是一部系统梳理中国古代 **38 种玄学秘术** 的综合性研究著作——太素脉法、盲派摸骨、奇门遁甲、铁板神数、祝由术、观落阴、茅山符箓、五雷正法、鲁班术、赶尸术……这些正经学术界见不到、民间口耳相传、再不记录就要彻底失传的东西。

每一章都遵循 **"古籍考证 → 正史纪实 → 民间访谈 / 田野调查 → 现代科学假说 → 传承反思"** 的五层叙事结构。不神化，不猎奇，不辟谣，只是尽可能忠实地记录。

> *这些术法，有的曾经是帝王的决策工具，有的是民间底层的生存智慧，有的在现代科学面前不堪一击，有的至今无法解释。无论如何，它们都是中华文明中真实存在过的一部分。*

## 全书结构

全书分为四编，共 35 章，覆盖 38 种秘术，总计 7.6 万字。

### 上编：感官异术与人体诊断

<img src="images/ch1_pulse.png" width="100%" alt="太素脉法——以脉知命的千年绝学" />

五种以人体感官为媒介的诊断与预测术。它们的共同特征是：**不借助任何外部工具，仅凭修炼者自身的感官能力，即可获取常人无法感知的信息。**

| 章节 | 术法 | 核心内容 |
|:---:|:---:|:---|
| 第一章 | **太素脉法** | 以脉知命的千年绝学，僧智缘"诊父之脉而能道其子吉凶" |
| 第二章 | **盲派摸骨** | 触骨知命的感官代偿奇术，张宁回忆录中的惊人纪实 |
| 第三章 | **望气术** | 从鸿门宴到生物光子的跨千年追踪 |
| 第四章 | **闻香识人** | 曾国藩"以鼻观人"的识人体系 |
| 第五章 | **听声辨命** | 管辂"闻声知死"的三国传奇 |

### 中编：术数预测与天命推演

<img src="images/ch6_qimen.png" width="100%" alt="奇门遁甲——帝王之学" />

## 精彩摘录

> **太素脉法**：嘉祐末年，一个来自随州的僧人被召入北宋都城开封。他被安排住在相国寺——这座始建于北齐天保六年的千年古刹。智缘的到来在京城引发了轰动。他的脉诊能力远超常规医术的范畴——不仅能诊断疾病，更能通过脉象读取一个人的社会地位、未来运势和吉凶休咎。

> **铁板神数**：倪匡坐定后，董慕节拨动算盘，报出一个数字，翻开条文："某年某月某日午时生。"倪匡大惊——这正是他的准确出生时辰。接着第二条："兄弟六人。"第三条："有一兄在大陆，生死不明。"

> **赶尸术**：田铁武回忆他最后一次赶尸经历时说："那是 1949 年冬天，我从沅陵接了三具尸体，要送回凤凰。路上遇到解放军的部队，我只好把尸体藏在路边的山洞里，等部队过去再继续走。那是我最后一次赶尸了。"

> **种生基**：2007 年，华懋集团主席龚如心去世，留下 830 亿港元遗产。随后曝光的遗嘱争夺案中，风水师陈振聪声称龚如心生前曾在他指导下"种生基"，花费数千万港元在广东某山头修建了一座巨大的生基墓穴，试图以此改变命运、延长寿命。
