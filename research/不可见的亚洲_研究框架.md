# 第二部扩容框架：从“选集”回到“术法图谱”

## 1. 规模校准

第一部之所以成立，不仅是因为有若干好故事，而是因为它完成了一个**38种中国古代玄学秘术的系统图谱**。第二部不能缩成16个跨文化散点；它应同样追求**约35–40个经核验的对象**，并为每一个对象交代名称、社群、历史脉络、具体现场、与中国传统的可比关系以及伦理边界。

第二部所收录的“对象”不限于狭义法术。为适应亚洲不同宗教传统，应同时纳入五类材料：

| 类型 | 说明 | 收录示意（仅为研究方向，待核验） |
|:---|:---|:---|
| 灵界分类 | 一个社会如何命名鬼、精灵、祖先、神祇、附体者与亡者 | *jinn*、*hantu*、*phi*、*nat*、御灵、*preta* |
| 专门角色 | 谁能与不可见者交涉，及其资格、限制与社会位置 | *bomoh*、*pawang*、*dukun*、乩童、巫女、僧侣、神巫 |
| 仪式体系 | 安置死者、解厄、沟通、净化、镇抚与保护的社会程序 | *ruqyah*、*gut*、*tovil*、祖灵祭、神社仪礼 |
| 物质与空间 | 护符、面具、神龛、祖灵屋、圣墓、山海与城市空间如何承载神圣性 | *keramat*、佛牌、*anting-anting*、*uma lulik* |
| 现代变体 | 工业化、平台、移民、旅游与国家治理如何重写传统 | 工厂附体、组屋神坛、城市护符经济、网络灵异叙事 |

## 3. 马来西亚不应只是一章，而是一个“交界面”

马来西亚建议至少承担**8个候选单元**，并按四层来研究：第一层是伊斯兰语境中的精灵与不可见者；第二层是马来传统中的治疗者、灵媒与地方禁忌；第三层是华人迁徙之后的神坛、乩童、拿督公与海峡神明；第四层是印度社群、殖民遗产、工厂和城市生活带来的新叙事。这里的目标不是把这些传统揉成“马来西亚巫术”，而是追问它们如何共同生活、互相借词、彼此设限，又在哪些地方发生冲突。

用户提到的“冷水”“bondie”等转写**暂不擅自纠正或替换**。它们可能是频道口语、方言、字幕误听、特定地方称呼或不同语言的转写；会在查看频道内容后列入“原词—可能拼写—语言—含义—权威来源”的核验表，再决定是否采用。

## 4. 全书的统一叙事单位

第二部仍沿用第一部的三线写法，但每章应增加一条跨境/现代线：

> **文献与物件考证 → 可定位的历史或当代现场 → 已公开的人类学访谈/社区叙述 → 迁徙、殖民、工业或平台如何改变它。**

没有可靠来源、只有惊悚故事的材料，只能作为“现代传播现象”出现，不能被编进术法图谱。对活态伊斯兰、佛教、印度教、神道与原住民传统，也不制作任何通灵、护符、草药或攻击性仪式的可操作说明。
